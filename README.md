# klymapo.github.io

Portafolio de Mario Martínez Horta (Klymapo · Atátoriz). Sitio estático en GitHub Pages: HTML, CSS y JavaScript sin compilación, sin claves y sin servicios de pago.

- `index.html`: pantallas (título, modos, partidas, créditos, contacto, opciones).
- `data.js`: proyectos y créditos en español e inglés. **Aquí se agregan o editan proyectos.**
- `app.js`: navegación, control con teclado, idioma y fechas en vivo desde la API pública de GitHub.
- `styles.css`: estética por modo (Analista: consola moderna; Narrador: noir).

Rutas directas: `#analista`, `#narrador`, `#creditos`, `#contacto`, `#opciones`, y `#analista/racoon` abre una ficha.

Privacidad: los proyectos privados solo muestran ficha, sin enlace al código.
